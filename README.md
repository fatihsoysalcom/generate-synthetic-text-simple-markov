# Generate Synthetic Text Simple Markov

This example demonstrates the concept of 'synthetic representations' by generating artificial text. It uses a simple Markov chain model to learn word sequences from a small Turkish corpus. The generated text mimics the structure of natural language, illustrating how synthetic data can be created based on patterns observed in real data.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt in the same directory and run: `python main.py`
